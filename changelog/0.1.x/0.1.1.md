# 0.1.1 — 2026-10-19

## Added

- **CPIC discovery**: search evaluated gene–drug pairs, retrieve guideline coverage and list genes, phenotypes and controlled vocabulary.
- **Genetic evidence**: translate source-supported diplotypes and allele statuses; inspect allele function, definitions and population frequencies.
- **Prescribing recommendations**: browse drug recommendations or match explicit gene results and genotypes; every source genetic prerequisite is required before returning matched prescribing text.
- **Source fidelity**: retain complete records, clinical caveats, provenance and guideline links on both MCP response surfaces, with bounded requests and deterministic pagination.
- **Installation**: npm, Claude Desktop bundle, editor install links and container configuration; private vulnerability reporting link.

## Fixed

- **Text recovery**: include available genes in recommendation error messages as well as structured data ([#1](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/1)).
- **Identifier validation**: reject malformed RxNorm and ATC selectors in linear time while preserving accepted prefixes and blank inputs ([#2](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/2)).
- **Genetic query privacy**: omit query URLs from budget errors and their log bindings; successful responses retain exact provenance ([#3](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/3)).

## Dependencies

- **Test tooling**: add `commonmark` 0.31.2 and `@types/commonmark` 0.27.10 for Markdown response parity checks.
