# 0.3.0 — 2026-10-28

## Added

- **Agent skill `pharmacogenomics-guidelines-guide`** — published in root `skills/` and served over MCP as the `skill://pharmacogenomics-guidelines-guide/SKILL.md` resource, with the `skill://{+path}` template; plugin installs and the `.mcpb` bundle load it directly. It covers where each identifier comes from, diplotype notation, and the gates between a lab result and a recommendation.

## Changed

- The MCP SDK moves to `@modelcontextprotocol/server` ^2.4.0 (mcp-ts-core 0.13.17).
- The Docker image's optional OpenTelemetry packages move to OpenTelemetry JS 3 (mcp-ts-core 0.13.17; installed by `scripts/install-otel.ts` at the framework's peer ranges).
- The `.mcpb` no longer ships the framework's build-only files (`changelog/`, `scripts/`, `templates/`, `CLAUDE.md`, `AGENTS.md`, config bases) (mcp-ts-core 0.13.18, [cyanheads/mcp-ts-core#791](https://github.com/cyanheads/mcp-ts-core/issues/791)).
- The bundle cleaner and packaging linter keep the MCP SDK's `dist/ext/skills/` runtime modules, which the server needs at startup (local port of [cyanheads/mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794), with selector tests).
- `.mcpbignore` adopts the template's root-anchored exclusions.
- New root Agent Plugins `plugin.json` and `mcp.json`.
- `skills/` ships in the npm package (`files`), and the Docker image copies it to the runtime stage.
- The bug report issue template collects the environment in one table.
- README Getting started uses `claude mcp add` for the hosted and local servers, and Docker and local-development steps move to their own sections.
- Framework skills and scripts are synced to 0.13.18, including the new `add-skill` skill.

## Fixed

- **HTTP memory leak** — 0.2.1 shipped on mcp-ts-core 0.13.16, whose HTTP transport retained about 71 KiB per request through the shutdown signal, so sustained HTTP traffic grew the heap until the process ran out of memory. mcp-ts-core 0.13.17 gives each exchange its own abort controller, released when the response ends ([cyanheads/mcp-ts-core#786](https://github.com/cyanheads/mcp-ts-core/issues/786)).
