# 0.4.0 — 2026-11-20

## Added

- **Gene panels** accept up to 25 genes in genotype and results maps in both views. Set `PGX_LARGE_GENE_PANELS=false` to restore the 10-gene cap. (#27)
- **Incomplete drug summaries** provide names where available and aggregate missing genes, missing named alleles, and row counts across the full result before paging. (#26)

## Changed

- **Allele and guideline pages** use the row limit up to 100 and omit `oversizedRow`. Set `includePopulationFrequencies: true` to receive joined `populationFrequencies` in allele results. (#28)

## Fixed

- **Named HLA alleles** required by otherwise applicable rows appear in incomplete diagnostics in both views, with prescribing and alert text withheld. (#20)
- **Pair-linked guidelines** appear in drug lookups, reverse drug listings, and recommendation no-table notices. (#23)
- **Past-end guideline pages** report the requested offset and known total for the active view. (#24)
- **Diplotype aliases** with spaces around the slash or matching gene prefixes resolve in diplotype lookup and genotype recommendations. (#25)
