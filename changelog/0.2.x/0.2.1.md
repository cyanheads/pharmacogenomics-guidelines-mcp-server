# 0.2.1 — 2026-10-24

## Added

- **`pgx_get_recommendations`** accepts opt-in `view: "test_alerts"` for complete source CDS examples, with independent alert and missing-gene paging; default responses retain the recommendation contract ([#18](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/18)).

## Changed

- **Read-page limits** accept positive safe integers above existing caps, clamp with notices, and expose effective limits consistently; matched and incomplete pages remain independent ([#17](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/17)).
- **Hosted connection metadata** advertises the public Streamable HTTP endpoint; development guidance and audit classification are synchronized, and Docker uses Bun 1.4.4.

## Fixed

- **Drug-mode matching** ignores unrelated validated panel genes while retaining overlap, conflict and complete-prerequisite checks ([#14](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/14)).
- **RxNorm/ATC schemas** advertise every supported casing while preserving blank normalization and linear malformed-input rejection ([#15](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/15)).
- **Explicit result kinds** are checked against source gene semantics before value matching; incompatible kinds return `unsupported_gene_result` instead of false empty results ([#16](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/16)).
- **Source links** pass raw labels and destinations to the framework Markdown builder, avoiding double escaping after the framework update.
