# 0.2.0 — 2026-10-20

## Changed

- **Provenance:** `rowVersions[].requestIndex` replaces `requestUrl`, and `path` is an RFC 6901 pointer to a returned record; recommendation `geneResolutions[].provenance` is removed. Consulted URLs remain exact, with one clickable link per distinct destination in each rendered block. ([#6](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/6))
- **`pgx_get_guideline`:** nested `drugs`/`pairs` arrays are replaced by `drugCount`/`pairCount`; use `view: "drugs"` or `"pairs"` with `by: "id"` for selected top-level pages. Allele/guideline results apply a 24,000-byte soft budget, retain indivisible rows, and clamp positive safe-integer limits above 100. ([#7](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/7))
- **Source schemas:** describe clinical lookup keys, scores, classifications and evidence levels precisely; omit redundant safe-integer schema bounds while retaining runtime validation. ([#11](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/11))
- **Development docs:** link reporting forms and document coverage and publication commands.

## Fixed

- **Genotype matching:** include partially specified multi-gene candidates and report missing prerequisites without prescribing text. ([#5](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/5))
- **Explicit results:** `mode: "results"` matches source phenotypes, activity scores or allele status across drugs, with optional drug/population filters and independently paged incomplete diagnostics. ([#12](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/12))
- **Empty results:** distinguish unresolved drugs, absent recommendation tables, population mismatches and past-end offsets, linking source guidelines where available. ([#8](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/8))
- **Selector/result errors:** identify the failed rule or map-entry position without echoing submitted genetic keys or values. ([#9](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/9))
- **Allele selectors:** match functional status case-insensitively as literal text and accept matching gene-prefixed star names after exact lookup misses. ([#10](https://github.com/cyanheads/pharmacogenomics-guidelines-mcp-server/issues/10))
